Getting Started

Install the desktop app or open the browser build, import your tasks, and start producing in minutes.

Quick start

Up to Speed now ships as a desktop app and still supports a browser-only workflow. Install the desktop build for the full local runtime, or open the browser build for quick read-only access.

Install the desktop app

bunx --bun uptospeed-desktop-installer

The installer downloads the latest desktop release for your OS, installs it into a user-writable location, and opens the app. If you prefer a browser-only workflow, keep using index.html directly.

Option A: Desktop app

Recommended. Installs the full localhost runtime, including local broker sync, live updates, and MCP-backed agent tools.

Option B: Browser mode

Open the static app directly for demos or inspection. For Flow Production Tracking live sync and agents, use the desktop runtime or the local server stack. See Server Config for setup.

Getting up and running

1

Install or open

Run the Bun install command for the desktop app, or open index.html in a modern browser for the static fallback.

2

Import your tasks

Drag a CSV onto the board, or connect to Flow Production Tracking via Settings. The app accepts Flow Production Tracking-compatible CSVs out of the box.

3

Start producing

Drag tasks between columns, switch views, and use the workload panel to balance your team's capacity and delivery plan.

CSV format

Import CSVs with these columns. All columns are optional except Task Name.

ColumnDescription
IdUnique task identifier
Task NameTask title
LinkAsset name
StatusCurrent status code (e.g. ip, review, apr)
Assigned ToArtist name
StartStart date (YYYY-MM-DD)
EndEnd date (YYYY-MM-DD)
Pipeline StepDepartment (Rig, CFX, Model, Look Dev, etc.)
% AllocationArtist allocation percentage
ProjectProject name

Views

Switch between views depending on what you're doing.

Board

Kanban-style columns. Drag tasks between Backlog, Scheduled, In Progress, Review, and Done.

Timeline

Gantt chart with drag-to-reschedule, resize-to-adjust, weekend highlighting, and a today marker.

Spreadsheet

Click any cell to edit. Sort by any column. Handles thousands of tasks without slowing down.

Rounds

Walk through each artist's tasks one by one. Built for dailies and stand-ups. Navigate with arrow keys.

Flow Production Tracking live sync

Optionally connect to a real Flow Production Tracking site to pull and push tasks. This requires running a small local server.

See the Server Config page for full setup instructions.

Browser support

Works in all modern browsers — Chrome, Firefox, Safari, and Edge. Data persists in localStorage, so your tasks survive page reloads.
