Server Config

Connect to Flow Production Tracking to keep creative projects aligned — optional and fully local.

Flow Production Tracking proxy server

The local proxy lets you pull tasks from a real Flow Production Tracking site and push changes back. It runs on your machine — nothing leaves your network except Flow Production Tracking API calls.

Authentication options

Flow Production Tracking's REST API uses token grants. The app supports two methods:

Studio script Recommended

Uses client_credentials via a script name and API key. Best for teams — no one needs to enter personal credentials.

Personal sign-in

Users sign in with their Flow Production Tracking API passphrase/token (not their Autodesk SSO password). No env vars needed.

1. Configure credentials

Copy .env.example to .env.local and fill in your values:

SHOTGRID_URL=https://your-studio.shotgrid.autodesk.com
SHOTGRID_SCRIPT_NAME=your-script-name
SHOTGRID_API_KEY=your-api-key

# Optional: default project id
SHOTGRID_PROJECT_ID=

For personal sign-in, you can leave the file empty — just set SHOTGRID_URL to pre-fill the site URL field in the UI.

2. Start the server

python3 server/shotgrid_server.py

3. Open the app

Navigate to http://127.0.0.1:7331/. If you open index.html directly instead, go to Settings → Flow Production Tracking and set the server URL to http://127.0.0.1:7331.

4. Connect and choose a project

Complete onboarding (or go to Settings → Flow Production Tracking → "Connect to Flow Production Tracking…"), pick your auth method, select a project, then use SG Sync to pull and SG Push to push.

Environment variables

VariableDescription
SHOTGRID_URLYour studio's Flow Production Tracking URL
SHOTGRID_SCRIPT_NAMEScript name for service account auth
SHOTGRID_API_KEYAPI key for service account auth
SHOTGRID_PROJECT_IDDefault project ID (optional)
SHOTGRID_CACHE_TTL_SECONDSCache TTL in seconds (default: 300, set 0 to disable)
SHOTGRID_DEBUGEnable verbose logging (1 to enable)
SHOTGRID_FIELD_DEPT_PROD_NOTECustom field name for department production notes
SHOTGRID_FIELD_TARGET_STATUS_SUMMARYCustom field name for target status
SHOTGRID_FIELD_TASK_COMMENTSCustom field name for task comments

Troubleshooting

If SG Sync fails, the UI shows the upstream Flow Production Tracking status and a hint when available. Enable verbose logging for more detail:

SHOTGRID_DEBUG=1 python3 server/shotgrid_server.py
StatusCause
401 / 400Invalid or expired credentials — reconnect or verify script name/key
403Permissions — script/user role can see projects but not tasks
404Wrong SHOTGRID_URL — must be your studio site
422Field mismatch — remove or adjust SHOTGRID_FIELD_* overrides

Performance notes

The proxy caches /api/shotgrid/tasks responses in-memory for 5 minutes by default and persists a small disk cache for fast restarts. Override with SHOTGRID_CACHE_TTL_SECONDS (set 0 to disable).

The browser UI loads cached tasks immediately and refreshes in the background when "Auto-sync on load" is enabled.
